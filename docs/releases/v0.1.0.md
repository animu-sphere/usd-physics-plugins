# v0.1.0 — the first versioned physics libraries

**Release status:** the tag `v0.1.0` is cut from the commit that adds this record,
after a green dry run of the [release workflow](../../.github/workflows/release.yml)
on `main`. The draft is published once Stage Runner's source CI passes on the
pushed digests, the downstream check the
[release schema](../architecture/RELEASE_SCHEMA.md#3-promotion-gates) requires.

## What ships

`physicsCore`, the Jolt-enabled `physicsJolt` and `physicsUsd`, each as its own
digest-pinned artifact. What each covers and its limits are in the
[capability matrix](../reference/CAPABILITY_MATRIX.md); the
[changelog](../../CHANGELOG.md) lists the additions.

## Compatibility

- **Targets:** `cy2026` / `usd` on Windows x86_64 and Linux x86_64, with OpenUSD
  26.08 and Python 3.13.
- **Jolt:** `physicsJolt` does not contain Jolt. It was built with the
  [published ABI set](../architecture/DEPENDENCIES.md#3-jolt-physics) and refuses
  any other SDK when a consumer configures. Its six-DOF capability is off.
- **API and ABI:** 0.x. A minor version may change either, and installed packages
  refuse an incompatible descriptor build.

## Known limitations

- Six-DOF constraints and neutral springs are experimental and are not in this
  package. They need the deterministic SDK.
- `physicsUsd` reads a declared subset of `UsdPhysics` and rejects the rest with
  typed diagnostics.
- These artifacts replace the earlier consumer-validation tags in the same OCI
  repository, which never established a release.
