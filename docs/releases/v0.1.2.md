# v0.1.2 — capacity and self-joints for real MMD models

**Release status:** the tag `v0.1.2` is cut from the commit that adds this record,
after a green dry run of the [release workflow](../../.github/workflows/release.yml)
on `main`. The draft is published once `usd-avatar-runtime`'s MMD session lanes pass
on the pushed digests, as for v0.1.1.

## What ships

`physicsCore`, `physicsJolt`, `physicsJoltSixDof` and `physicsUsd`, each as its own
digest-pinned artifact. The [changelog](../../CHANGELOG.md) lists the changes.

## Compatibility

- **`createWorld`:** a new overload takes a `WorldCapacity`, stated by
  `physicsJolt_WORLD_CAPACITY_VERSION`. The existing overloads and their defaults are
  unchanged.
- **`physicsUsd`:** reads a disabled joint that repeats an endpoint, which it refused
  before. An enabled one still rejects.
- **Jolt:** each backend's SDK is as in v0.1.1.

## Known limitations

- A larger capacity costs memory for the world's lifetime. The defaults still suit only
  small scenes, and exhausting them fails the step.
- Six-DOF constraints and neutral springs stay experimental.
